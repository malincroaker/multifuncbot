# Multifuncbot

[English](README.md) | Русский

Модульный бот для портфолио: пользователь выбирает сценарий и проходит путь клиента.
Из тех же модулей можно собрать отдельного бота для заказчика.

Проект создаётся поэтапно, с проверками и отдельными коммитами.
[Архитектура](docs/architecture.md) · [Этапы](docs/roadmap.md).

В первой версии: пошаговый помощник, запись на услуги, заявки и магазин Mini App
с корзиной, оформлением заказа и явно обозначенной имитацией оплаты. Интерфейс — русский и английский.

Настоящие деньги не списываются. Организации, товары и цены — демонстрационные.
