# Implementation stages

1. Project skeleton, configuration, database, registry and CI.
2. Scenario navigation and bilingual Stepwise module with persistent progress and PDFs.
3. Studio booking and lead collection, customer/demo admin views and reminders.
4. Shop domain, cart, idempotent checkout, demo payment states and order history.
5. Shop API, verified Mini App identity and responsive bilingual catalogue.
6. End-to-end checks, packaging, client extraction guide and GitHub publication.

Later extensions: support tickets, CRM adapters, YooKassa test-store integration,
Telegram Stars for digital goods and production hosting. These are not included as working features.

The first release demonstrates physical stationery products and studio appointments.
The payment simulator is labelled throughout and cannot charge a user.
