# Multifuncbot

English | [Русский](README.ru.md)

A modular Telegram portfolio bot: visitors choose a scenario and try a complete customer workflow.
The same modules can be selected for a standalone client bot.

Implementation is being built in small, independently verified commits. See
[the architecture](docs/architecture.md) and [the implementation stages](docs/roadmap.md).

Planned first release: bilingual guided onboarding, appointment booking, lead collection,
and a shop Mini App with a cart, checkout and explicitly simulated payments.

No real money is collected. All sample businesses, products and prices are demonstration data.
